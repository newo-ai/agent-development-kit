How to use the attribute reference:
1. Find the attribute in [attributes/index.md](attributes/index.md): IDN, title with the setup tier
   (A basic, B common, C advanced; [IMPORTANT] changes behavior a lot), level and value type.
2. Open its group page for the full description, examples, defaults and dependencies.
3. Before changing a value, read the live `description` on the account too: if it differs from
   this reference, trust the live value and tell the person.
