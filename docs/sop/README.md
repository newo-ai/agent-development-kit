# SOPs: steps a person does by hand

Short procedures for the few steps your assistant cannot do for you. Your assistant tells you
when you need one. Each SOP ends by telling you what to say to the assistant next.

| SOP | You need it when |
|---|---|
| [Connect the Newo MCP](connect-newo-mcp.md) | The first time you use the kit, in each AI app you use |
| [Get an API key](get-api-key.md) | Only when your assistant asks for one, for a task the MCP can't do |
| [Edit a scenario](edit-a-scenario.md) | The agent must handle a conversation differently and no setting does it |

Stuck at any point? Tell your assistant "I'm stuck".
